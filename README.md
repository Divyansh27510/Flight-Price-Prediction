# ✈️ Flight Price Prediction

A machine learning regression project that predicts flight ticket prices based on flight-related features.

## 📌 Overview

This project focuses on predicting flight ticket prices using machine learning techniques.

The project follows a complete machine learning workflow, including data exploration, data preprocessing, feature engineering, model training, and evaluation.

## 🎯 Problem Statement

Flight ticket prices can vary depending on several factors such as airline, source, destination, duration, number of stops, and journey details.

The objective of this project is to build a regression model that can learn these relationships and predict the price of a flight.

## 🔍 Exploratory Data Analysis

The dataset was explored to understand:

- Distribution of flight prices
- Price variation across airlines
- Effect of source and destination
- Relationship between flight duration and price
- Effect of number of stops on price
- Distribution of important numerical features
- Relationships between different features

## ⚙️ Data Preprocessing

The preprocessing workflow includes:

- Handling missing values
- Cleaning the dataset
- Converting date and time information
- Extracting useful features from existing columns
- Encoding categorical variables
- Preparing numerical features
- Splitting the dataset into training and testing sets

## 🤖 Machine Learning

This is a **supervised regression problem**.

The machine learning model learns the relationship between flight-related features and ticket prices and uses this relationship to predict prices for unseen data.

## 📊 Model Evaluation

The performance of the regression model is evaluated using appropriate regression metrics.

Common metrics include:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score
